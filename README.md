# Linux File System

A basic file system built from scratch in C as a team project at San Francisco State University (November 2022). It was developed and tested in a Linux environment.

## My Contribution

I worked on a team of four and built:

- **Volume formatting:** initializing a volume so it's ready to hold files
- **Basic directory functions and operations:** create, list, remove, copy, history


## Features

- Volume formatting
- Directory operations
- File creation
- File reading
- File writing
- File deletion and moving

## Tech

- **Language:** C
- **Environment:** Linux
- **Tools:** make, Git

## Build and Run

```bash
git clone [repo URL]
cd [project folder]
make
./[executable name] [arguments, e.g., volume file name and size]
```

## How It Works

In this project, we designed a file system that essentially encompasses all the
components we have learned about the Linux File System in order to make our own
implementation. While not as robust and polished like the Linux file system, our file system
can manage files and directories while also being able to display information about a file or
directory. At the minimum, we were able to implement the basic functionalities of a file
system that most operating system’s file systems have today.
